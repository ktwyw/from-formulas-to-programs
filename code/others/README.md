# Fragments from Chapters 5, 9 and 14

These files are copies of the short examples printed in the book. **They were checked by
hand and have not been compiled or run**; each needs its own tool:

| File | Language | Tool |
|---|---|---|
| `friction_and_drag.bas` | VBA | the Visual Basic editor of Microsoft Excel (Alt+F11) |
| `tank_control.st` | Structured Text (IEC 61131-3) | a PLC environment such as CODESYS |
| `counter4.v` | Verilog | a simulator such as Icarus Verilog, or an FPGA tool |
| `counter4.vhd` | VHDL | a simulator such as GHDL, or an FPGA tool |
| `FallingBody.mo` | Modelica | OpenModelica |
| `pocket.gcode` | G-code | a CNC simulator; do not run on a machine without checking |
| `fan_control.ino` | Arduino (C++) | the Arduino IDE, with a TMP36 sensor on pin A0 |
| `material.ts` | TypeScript | `tsc`; the last two lines are deliberate type errors |
